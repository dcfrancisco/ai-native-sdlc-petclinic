# Apply the Lifecycle to Your Software

Choose one bounded capability in software you own or understand. For each book chapter, produce the equivalent engineering function rather than copying PetClinic artifacts mechanically.

Ask:

- What outcome matters?
- Which sources are authoritative?
- Which decisions require human ownership?
- Which ecosystem boundaries make the work consequential?
- What may AI contribute?
- What evidence would justify acceptance?
- What tools can produce that evidence?
- What conditions must stop the work?

Your project may use a different language, architecture, build system, deployment model, and risk profile. Successful transfer means you can leave PetClinic behind.

Use the [chapter-by-chapter transfer workbook](transfer-workbook.md) to carry one capability through the full lifecycle.
