# Controlled AI Contribution Experiment

**Related chapters:** 8 and 17

## Question

For the same bounded work package, how do a minimal instruction and a structured contribution contract differ in observable engineering outcomes under controlled conditions?

## Fixed conditions

- identical clean baseline revision;
- identical work package;
- identical model and tool version;
- identical context availability, except for instruction content;
- identical permissions;
- independent workspaces;
- identical time limit;
- identical acceptance tests and reviewers.

## Conditions

- Condition A: `condition-a-minimal-instruction.md`
- Condition B: `condition-b-structured-instruction.md`

## Record for each execution

- execution ID and date;
- model and tool version;
- baseline checksum;
- context visible to the AI;
- permissions;
- generated and corrected changes;
- files modified;
- tests and functional checks;
- scope violations;
- review findings;
- human correction effort;
- time to review-ready and accepted states;
- limitations and interruptions.

## Evaluation

Use `experiment-record-template.md`. Do not substitute impressions for measurements. Do not erase failed attempts. Do not claim universal productivity effects.

## Current evidence status

The protocol and both conditions are complete. No comparative result is published because independent executions have not yet been performed from clean, equivalent baselines. This is an honest unexecuted experiment, not a placeholder result.
