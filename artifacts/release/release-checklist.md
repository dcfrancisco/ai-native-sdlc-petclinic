# Reminder Release Checklist

**Chapter:** 14
**Status:** Reference checklist

- [ ] Pinned baseline and derived version recorded
- [ ] Formatting, compilation, and full regression suite pass
- [ ] Reminder unit, MVC, and integration tests pass
- [ ] PostgreSQL and MySQL checks reported
- [ ] Application image builds and starts
- [ ] Human reminder workflow passes
- [ ] Idempotency is observed
- [ ] Metrics are visible
- [ ] Security findings are resolved or explicitly accepted
- [ ] Governance approvals are present
- [ ] Documentation and traceability are current
- [ ] Rollback procedure is rehearsed
- [ ] Monitoring and incident ownership are assigned
- [ ] Known limitations are included in release notes

Completing the boxes does not grant production acceptance. The accountable release owner reviews the evidence and residual risk.
