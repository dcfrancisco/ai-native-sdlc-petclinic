# Human and AI Responsibility Matrix

**Chapter:** 16
**Status:** Accepted for the companion workflow

| Activity | Human owner | AI contribution | Required evidence |
|---|---|---|---|
| Problem framing | Product or domain owner | Expose ambiguity and counterexamples | Accepted requirements |
| Architecture | Architect | Compare options and consequences | ADR and diagrams |
| Planning | Technical lead | Decompose and identify dependencies | Approved work packages |
| Implementation | Engineer | Generate and revise bounded changes | Diff and focused tests |
| Testing | Test owner | Propose and implement tests | Independent results |
| Review | Assigned reviewer | Find defects by role | Findings and corrections |
| Security | Security owner | Threat analysis and code review | Security assessment |
| Release | Release owner | Assemble and check evidence | Release decision |
| Operations | Service owner | Analyze signals and incidents | Runbook and incident record |

AI does not approve its own work, own credentials, accept residual risk, or decide product and policy questions without delegated human authority.
