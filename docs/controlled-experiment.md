# Controlled AI Contribution Experiment

The controlled experiment compares the same approved work package under two instruction conditions.

Condition A provides only `labs/controlled-experiment/condition-a-minimal-instruction.md`.

Condition B provides the structured contribution contract and the same baseline permissions.

The protocol, evidence schema, and interpretation rules are in `labs/controlled-experiment/README.md`.

The repository does not claim that one condition universally improves productivity. Results depend on model, tool, task, context, permissions, environment, evaluator, and time. Publish observed differences and limitations only.

No experiment result may be invented from the completed reference implementation. An experiment is publishable only after both conditions are executed independently from the same clean baseline and evaluated against the same acceptance criteria.
