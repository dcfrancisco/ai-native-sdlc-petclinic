# Book Mapping

The book and repository use the same progression. Start with the chapter question, perform the lab, inspect the corresponding artifact, and then create the equivalent artifact for your own software.

| Book part | Companion emphasis |
|---|---|
| Part I | Partnership, accountability, and lifecycle model |
| Part II | Context, requirements, architecture, planning, and contribution contracts |
| Part III | Implementation, evidence, review, documentation, and memory |
| Part IV | Security and governance, release, operations, and measurement |
| Part V | Operating model, adoption, and durable engineered delivery |

See [Chapter Mapping](chapter-mapping.md) for exact files.
